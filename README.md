# Residual study of pixel hit position towards ML-based noise fitration

In this project, we simulated 10 GeV muons in CLD detector and extracted the data from innermost layer of tracking detectors and Monte Carlo truth information. We calculated the residual between the positions in the sensors where the particle crosses and the expected position in the sensors where particle crosses. 

## simulation
run the script sim.sh

## root to hdf5 data conversion
run the script root_2hdf5.sh (with proper location of the data files)
